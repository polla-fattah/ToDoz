Let an AI add your tasks

Tell Claude, ChatGPT or Gemini "add a task: call the dentist tomorrow 10am" and it lands in ToDoz on all your devices. It takes about five minutes, once.

1 Make a key in ToDoz

  1. Open ToDoz (the app, or the web app).
  2. Go to Settings → Calendar and integrations → API access.
  3. Make a new key. Name it after the assistant, like Claude.
  4. Tick read only if the assistant should only look at your tasks, not change them.
  5. Copy the key now. It starts with tf_ and is shown only once.

2 Make your private address

Paste the key here. The address is made in your browser; nothing is sent anywhere.

https://…/mcp/tf_YOUR_KEY

This address is a password. Do not post it or send it to anyone. If it leaks, delete the key in ToDoz (step 1) and make a new one.

3 Give it to your assistant

Claude (claude.ai, desktop, phone)
  1. Open claude.ai → Settings → Connectors → Add custom connector.
  2. Name: ToDoz. Address: paste yours from step 2. Leave every other box empty.
  3. Start a new chat and switch the ToDoz connector on.

Custom connectors may need a paid Claude plan. Connectors you add on the web should show up in the phone app too.

ChatGPT
  1. Settings → Apps → Advanced → turn on Developer mode.
  2. Create a new app or connector. Address: paste yours. Authentication: No authentication.
  3. In a chat, pick the ToDoz app from the tools menu.

Developer mode is a beta and only some plans have it. If you do not see it, your plan does not have it yet.

Gemini

The Gemini app may offer Connected apps → Other → Add a custom app. Paste your address there. Google only gives this to some plans, so you may not see it.

If you use the Gemini command line tool, this always works (replace the key):

gemini mcp add --transport http --header "Authorization: Bearer tf_YOUR_KEY" todoz https://todoz.polla.dev/mcp

4 Try it

In a new chat with ToDoz switched on, say:

  • "Add to ToDoz: buy milk tomorrow 5pm."
  • "What is on my ToDoz list for today?"
  • "Mark 'buy milk' as done."

The task appears in ToDoz at the next sync. Say your time zone once ("I am in Erbil"), so "tomorrow" is your tomorrow.

? Something is wrong

  • "Could not connect" or "token not accepted": the address has a typo, or the key was deleted. Redo step 2 with a new key.
  • It will not add, only look: the key is read only. Make a new key without that tick.
  • I do not see "custom connector": your plan may not include it yet. Gemini CLI and Claude Code on a computer always work: see the full docs.
  • Stop an assistant for good: delete its key under API access in ToDoz. It stops working at once.
